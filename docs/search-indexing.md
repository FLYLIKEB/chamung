# Search indexing

Canonical host: `https://www.chamung.com` (existing apex domain redirects here).

- `/robots.txt` declares `/sitemap.xml` and permits rendering resources. Authentication remains the access-control boundary.
- `/sitemap.xml` is an XML sitemap index. `/sitemaps/static.xml`, `teas.xml`, `notes.xml`, and `posts.xml` are generated by `api/sitemap.ts` using `BACKEND_URL`, the same setting as the existing API proxy.
- Dynamic maps use unauthenticated public APIs, real record IDs and modification timestamps; notes additionally require `isPublic === true`. Private, editing, login and account-only routes are excluded. No visitor credentials are forwarded.
- Dynamic maps are CDN-cached for five minutes. Upstream failures return 503/no-store rather than an incomplete 200 sitemap. Invalid kinds return 404. Large maps fail at the sitemap limit instead of silently dropping URLs; partition further before reaching 50,000 records per kind.
- Known account/editing routes send `X-Robots-Tag: noindex, follow`. Client route metadata covers other non-public routes and missing/private detail records. Do not block those routes in robots.txt, since crawlers need to read the noindex directive.
- Public detail pages apply title, description and canonical after data loads; query variants are noindex with a canonical path without the query. HTML shell contains Korean site metadata and Open Graph/Twitter defaults, not a universal home-page canonical.
- Public note, tea and post cards expose ordinary links while keeping menus and bookmark controls separate.

## Verification

Check XML HTTP status/content type and parse every sitemap child; compare note entries with the anonymous public API. Check `/login` and `/note/new` noindex headers and confirm a public `/note/129` has no server noindex header. Test dynamic metadata after client navigation and after loading a private note.

This is a client-rendered app: detail metadata requires JavaScript rendering, and non-JavaScript social crawlers receive the site defaults. Server rendering is a separate improvement. Sitemap publication does not itself submit a Search Console property or prove indexing.
